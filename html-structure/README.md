# DentaFlow \| Dentist Appointment

DentaFlow is a proposed web-based dental appointment scheduling system
designed to help clinic staff organize patient appointments, manage
dentist schedules, and coordinate dental services efficiently. The
application also provides patients with a browser-based interface for
accessing appointment-related features and dental service information.

## Project Overview

DentaFlow focuses on providing a simple and organized browser-based
experience for dental appointment scheduling. The current project is
being developed using HTML, CSS, and JavaScript.

The application includes frontend pages and interactions for navigation,
account registration and login, appointment requests and cancellations,
patient and admin dashboards, dental services, help information, and
other supporting content.

## Current Development Scope

The current development focuses on the frontend of DentaFlow using HTML,
CSS, and JavaScript. Testing covers the webpage structure, visual
layout, navigation, forms, modal interactions, and responsiveness across
different browser viewport sizes.

The project is still under development, so existing pages, interactions,
responsive design, and other features may continue to be refined or
expanded as development progresses.

Note => For Login, since the web application is in its early stages, you can put any values inside the text fields or none at all, to go to the admin dashboard, just simply click the Login button.
